# Plotbench branding

The results website and presentation assets share the same waveform and outlined
wordmark. SVG lettering is stored as paths, so no font installation is needed.

| Asset | Use |
| --- | --- |
| `plotbench-banner.png` / `.svg` | 3200 × 1000 navy banner for presentations |
| `plotbench-wordmark-on-dark.png` / `.svg` | Transparent pale wordmark and mint mark for dark slides |
| `plotbench-wordmark-on-light.png` / `.svg` | Transparent navy wordmark and darker teal mark for light slides |
| `plotbench-icon.svg` | Matching favicon on a rounded navy tile |

The transparent PNGs are 3300 × 660. Prefer SVG when your slide software supports
it, and preserve the aspect ratio when resizing. PNGs provide a compatible
alternative. The banner has no tagline, so it can accompany different talk titles.

Colors: navy `#111e28`, pale blue `#dce8ef`, mint `#64dccc`; on light backgrounds
use teal `#087f73` for the mark. The outlined lettering was set in Helvetica Neue
Bold with slightly tightened spacing.

The mark's native geometry is `M4 30H13L21 10L31 44L42 6L51 30H62`, with a
3-unit stroke and round caps and joins. Keep it consistent in the wordmarks,
banner and favicon when editing the SVG masters; re-export the PNGs afterward.
